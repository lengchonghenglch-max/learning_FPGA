### [2026-06-07] linetest 发送握手理解
- 问题描述：不清楚为什么 `tail` 不能在 `run_tx = 1` 后每拍自增。
- 现象：直觉上只要进入发送阶段，就好像可以连续读出后续字节。
- 原因分析：UART 发送器存在 `busy` 握手，只有发送器在当前拍接受了这个字节，`tail` 才能安全指向下一个字节。
- 解决方法：结合 `tx_stb`、`tx_busy` 和 `tail` 的关系分析发送握手。
- 验证结果：确认 `tail` 只应在 `tx_stb && !tx_busy` 时前进，否则会跳过未真正送入发送器的数据。
